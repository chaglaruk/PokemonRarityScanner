== The 10-second version

PokeRarityScanner watches a live Pokémon GO detail screen on a real Android device. It extracts text, evaluates visual variant evidence, checks historical event windows and produces a bounded rarity decision that explains _why_ the result received its score.

[cols="1,1,1,1",options="header"]
|===
| Read
| See
| Verify
| Explain

| Species, CP, HP and caught date
| Shiny, shadow, costume, form and special backgrounds
| Species consistency and date-backed event context
| Rarity tier, score components and evidence labels
|===

== What the scanner sees

image::docs/assets/readme-feature-grid-v2.svg[Four scanner evidence layers,width=100%]

The scanner deliberately separates species authority from variant evidence. A visual classifier may strengthen a costume or form decision, but it is not allowed to silently replace a strongly established species identity.

== A rarity score you can inspect

image::docs/assets/readme-rarity-spectrum-v2.svg[Rarity tier scale,width=100%]

[source,text]
----
totalScore =
  baseSpeciesAxis  0..35
+ variantAxis      0..35
+ ageAxis          0..20
+ collectorAxis    0..10

final score = clamp(totalScore, 0, 100)
----

The additive model replaced multiplier-heavy scoring. Weak evidence can no longer inflate the result beyond the contribution allowed for its axis.

[cols="1,1,3",options="header"]
|===
| Axis
| Range
| Evidence

| Base species
| 0..35
| Generated species rarity metadata

| Variant
| 0..35
| Shiny, costume, shadow, lucky, form, background and supported combinations

| Age
| 0..20
| Caught-date age tiers

| Collector
| 0..10
| Size, rare gender and date-backed event context
|===

== Why event dates matter

A costume can return in several years. A matching sprite alone is therefore not enough to claim a named event.

[cols="1,2,2",options="header"]
|===
| Evidence
| Result label
| Scoring effect

| Costume detected + caught date inside an authoritative event window
| Named event and release window may be shown
| Event-backed evidence may contribute

| Costume detected + no matching caught-date window
| Generic costume or form label only
| Costume evidence remains; named-event bonus is suppressed
|===

This prevents a Pokémon caught in an earlier year from being presented as a later repeated-costume event merely because the visual asset looks similar.

== Decision pipeline

image::docs/assets/readme-scan-flow-v2.svg[Scanner decision pipeline,width=100%]

[source,text]
----
ScreenCaptureService
  -> OCRProcessor + TextParser
  -> SpeciesRefiner + consistency gates
  -> VisualFeatureDetector + variant decision
  -> Historical event resolver
  -> RarityCalculator
  -> Overlay UI
  -> optional consent-gated private telemetry
----

== Recognition quality gates

The repository includes deterministic characterization data and fixture-integrity checks so recognition changes are measured instead of judged only by appearance.

++++
<div align="center">
  <table>
    <tr>
      <td align="center"><strong>1,011</strong><br><sub>canonical species in the characterization corpus</sub></td>
      <td align="center"><strong>44</strong><br><sub>recorded scan fixture entries</sub></td>
      <td align="center"><strong>0</strong><br><sub>corrupt or missing fixture files</sub></td>
      <td align="center"><strong>Fail closed</strong><br><sub>when species evidence is unsafe</sub></td>
    </tr>
  </table>
</div>
++++

Important distinction: the generated OCR mutation corpus characterizes parser behavior; it is not presented as a substitute for a full camera-image benchmark. Real-device scans remain the ground truth needed to harden costume, shiny and background recognition.

== Build it

Requirements:

* Android Studio with JDK 17
* Android SDK 35
* A physical Android device for live screen-capture validation
* ADB for installation and diagnostics

[source,powershell]
----
git clone https://github.com/chaglaruk/PokemonRarityScanner.git
cd PokemonRarityScanner

.\gradlew.bat :app:testDebugUnitTest --no-daemon --console=plain
.\gradlew.bat :app:assembleDebug --no-daemon --console=plain
----

Debug APK:

[source,text]
----
app/build/outputs/apk/debug/PokeRarityScanner-v<version>-debug.apk
----

Install and launch:

[source,powershell]
----
adb install -r app\build\outputs\apk\debug\PokeRarityScanner-v<version>-debug.apk
adb shell monkey -p com.pokerarity.scanner -c android.intent.category.LAUNCHER 1
----
